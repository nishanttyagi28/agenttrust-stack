# ADR 0007: Publish as nishanttyagi-agenttrust

**Status:** Accepted. Distribution name is `nishanttyagi-agenttrust` 0.1.0. Publish is Trusted Publisher on tag `v*`.  
**Date:** 2026-10-07

## Current decision

The PyPI project name is `nishanttyagi-agenttrust`. Version stays `0.1.0`. Imports stay `agenttrust`.

PyPI rejected `agenttrust-stack` as too similar to an existing project. That name is not the distribution name.

`pyproject.toml` depends on `nishanttyagi-agenteval>=0.5.0,<0.6`. AgentEval **0.5.0** is https://pypi.org/project/nishanttyagi-agenteval/0.5.0/. Provenance SHA `99fa7a5f4edafd44acb6c68d23cb871eb539b7d7`. Exit 3 calls `agenteval.core.compare.compare_runs` (ADR 0005).

Publish uses `.github/workflows/publish.yml` on a `v*` tag. The pending publisher is repository `nishanttyagi28/agenttrust-stack`, workflow `publish.yml`, environment **(Any)**. The workflow does not set a GitHub environment. It requests `id-token: write` and uses `pypa/gh-action-pypi-publish`. No PyPI token is stored in this repo. This change does not run `twine upload`.

Install: `pip install nishanttyagi-agenttrust`. Clone installs stay `pip install -e ".[dev,karmasakshi]"`.

If `compare_runs` cannot be imported, exit 3 logs `agenteval compare unavailable; local ground_truth check` and uses the local containment check. That fallback stays.

## Context

`pyproject.toml` depends on

`nishanttyagi-agenteval @ git+https://github.com/nishanttyagi28/agenteval.git@99fa7a5f4edafd44acb6c68d23cb871eb539b7d7`

PyPI rejects a direct URL dependency. Checked 2026-10-07 with `python -m pip index versions nishanttyagi-agenteval`:

| Source | Version |
|---|---|
| PyPI latest | **0.3.0** (also 0.2.0, 0.1.0) |
| Installed from the pin | **0.5.0** at SHA `99fa7a5f4edafd44acb6c68d23cb871eb539b7d7` |

`agenttrust-stack` itself is not on PyPI (`No matching distribution found`).

Exit 3 calls `agenteval.core.compare.compare_runs` from that SHA (ADR 0005). PyPI 0.3.0 is the release ADR 0001 already treated as missing those 0.5.0 APIs. This slice did not re-audit the 0.3.0 sdist; it does not pin 0.3.0.

`karmasakshi-protocol>=0.2,<0.3` is already the optional extra `karmasakshi` and is on PyPI.

## Decision (earlier the same day)

**Path 1. Do not publish `agenttrust-stack` until AgentEval 0.5.0 exists on PyPI. Do not replace the git URL with a version that is not on PyPI.**

Publish order:

1. Publish `nishanttyagi-agenteval` **0.5.0** from the agenteval repo (the release that contains `compare_runs` at SHA `99fa7a5f4edafd44acb6c68d23cb871eb539b7d7`, or a newer 0.5.x that still has that function). **Done.** Trusted Publisher on GitHub release `v0.5.0`.
2. Then change this dependency to `nishanttyagi-agenteval>=0.5.0,<0.6` and keep the SHA in this ADR as provenance. **Done in this change.**
3. After the human approved publish: Trusted Publisher for `nishanttyagi-agenttrust` 0.1.0, tag `v0.1.0`. **This change.** `twine upload` is not used. PyPI rejected the name `agenttrust-stack` as too similar, so the distribution name is `nishanttyagi-agenttrust`.

## Alternatives considered

- **Pin PyPI 0.3.0 now.** Rejected. It is not the reviewed SHA, and this repo does not claim 0.3.0 provides `compare_runs`.
- **Move the git URL to an optional extra so the core wheel has no direct URL.** Not this decision. That is the fallback if 0.5.0 cannot be published. It was not taken, because the preferred order is to publish AgentEval first and then depend on it directly.
- **Upload this package with the git dependency anyway.** Rejected. PyPI will not accept it.

## Consequences

A local `twine check` does not upload. Upload happens only when the `v*` tag runs `publish.yml`.
