# ADR 0007: PyPI is blocked until AgentEval 0.5.0 is published

**Status:** Accepted  
**Date:** 2026-10-07

## Context

`pyproject.toml` depends on

`nishanttyagi-agenteval @ git+https://github.com/nishanttyagi28/agenteval.git@99fa7a5f4edafd44acb6c68d23cb871eb539b7d7`

PyPI rejects a direct URL dependency. Checked 2026-10-07 with `python -m pip index versions nishanttyagi-agenteval`:

| Source | Version |
|---|---|
| PyPI latest | **0.3.0** (also 0.2.0, 0.1.0) |
| Installed from the pin | **0.5.0** at SHA `99fa7a5f4edafd44acb6c68d23cb871eb539b7d7` |

`agenttrust-stack` itself is not on PyPI (`No matching distribution found`).

Exit 3 calls `agenteval.core.compare.compare_runs` from that SHA (ADR 0005). PyPI 0.3.0 is the release ADR 0001 already treated as missing those 0.5.0 APIs. This slice did not re-audit the 0.3.0 sdist; it does not pin 0.3.0.

`karmasakshi-protocol>=0.2,<0.3` is already the optional extra `karmasakshi` and is on PyPI.

## Decision

**Path 1. Do not publish `agenttrust-stack` in this commit. Do not replace the git URL with a version that is not on PyPI.**

Publish order, later, in a separate change:

1. Publish `nishanttyagi-agenteval` **0.5.0** from the agenteval repo (the release that contains `compare_runs` at SHA `99fa7a5f4edafd44acb6c68d23cb871eb539b7d7`, or a newer 0.5.x that still has that function). That publish is not this repository.
2. Then change this dependency to `nishanttyagi-agenteval>=0.5.0,<0.6` and keep the SHA in this ADR as provenance.
3. Only after a human message that is exactly `upload now`: `twine upload` or a Trusted Publisher, then tag `v0.1.0`. No token is stored in this repo. This commit does not configure a Trusted Publisher.

Until step 2, `pip install agenttrust-stack` is not a supported command. Clone installs stay `pip install -e ".[dev,karmasakshi]"`.

If `compare_runs` cannot be imported, exit 3 already logs `agenteval compare unavailable; local ground_truth check` and uses the local containment check. That fallback stays.

## Alternatives considered

- **Pin PyPI 0.3.0 now.** Rejected. It is not the reviewed SHA, and this repo does not claim 0.3.0 provides `compare_runs`.
- **Move the git URL to an optional extra so the core wheel has no direct URL.** Not this decision. That is the fallback if 0.5.0 cannot be published. It was not taken, because the preferred order is to publish AgentEval first and then depend on it directly.
- **Upload this package with the git dependency anyway.** Rejected. PyPI will not accept it.

## Consequences

`python -m build` and `twine check` may pass on metadata while upload is still forbidden. A green check is not permission to upload.
